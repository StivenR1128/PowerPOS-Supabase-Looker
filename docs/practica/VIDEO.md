# Guion del video demostrativo

Duración sugerida: 4–6 minutos. Grabar la aplicación real, no una presentación de pantallas simuladas. Ocultar contraseñas y cadenas de conexión.

| Tiempo | Acción y evidencia |
|---|---|
| 0:00–0:35 | Presentar el repositorio independiente, README y DER de 26 tablas |
| 0:35–1:00 | Mostrar las tablas pobladas de Supabase y el historial de fechas |
| 1:00–1:50 | Iniciar sesión en la web, crear un producto con nombre identificable, editarlo y mostrar sus valores en Supabase |
| 1:50–2:40 | Registrar una venta en POS; mostrar número, importe y estado; verificar pedido, detalles e ingreso en Supabase |
| 2:40–3:00 | Recargar web y demostrar que la venta persiste |
| 3:00–4:10 | Abrir dashboard con Looker real; explicar tarjetas, línea y barras/circular; cambiar rango de fechas y categoría |
| 4:10–4:40 | Actualizar la fuente/informe cuando corresponda; mostrar nueva venta y explicar frescura/caché |
| 4:40–5:00 | Mostrar adaptación móvil y enlaces de entrega |

La eliminación de un producto puede ser lógica (`activo=false`); indicarlo y mostrar el registro correspondiente. Los pedidos se anulan para conservar el historial, en vez de borrarlos físicamente.

No se ha producido el video mientras no exista la instancia real, el informe y el despliegue verificados. Subirlo con acceso de visualización para el docente y guardar su enlace en ENTREGA.md.
